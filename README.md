# ARPWEAVER FM

ARPWEAVER FM is a Windows-first Wwise Source Plug-in project for real-time DX7-style FM synthesis with SysEx preset import, global scale control, chord generation, step sequencing, and lightweight FX.


## Main Folders

- `SoundEnginePlugin`
  - Runtime DSP
  - FM voice engine
  - chord generation
  - sequencer
  - chorus, delay, reverb, unison
- `WwisePlugin`
  - Authoring UI
  - property definitions
  - SysEx browser logic
  - bank serialization
- `FactoryAssets`
  - packaging manifest
- `docs`
  - historical notes copied from the migration base

## Core Files

- `ArpweaverFmConfig.h`
  - Plug-in identity
  - Company ID and Plug-in ID
- `Dx7RuntimeShared.h`
  - Runtime patch model shared between authoring and runtime
- `WwisePlugin\Dx7SysexSupport.h`
  - DX7 SysEx parsing helpers
- `WwisePlugin\ArpweaverFm.xml`
  - Wwise property schema
- `WwisePlugin\ArpweaverFmPlugin.cpp`
  - Authoring-side property handling and bank serialization
- `WwisePlugin\Win32\ArpweaverFmPluginGUI.cpp`
  - Win32 authoring UI
- `SoundEnginePlugin\ArpweaverFmSourceParams.h`
  - Runtime parameter structure
- `SoundEnginePlugin\ArpweaverFmSourceParams.cpp`
  - runtime parameter deserialization
- `SoundEnginePlugin\ArpweaverFmSource.cpp`
  - FM synth, sequencer, chord, FX runtime

## Current Scope

- Independent Wwise Source Plug-in identity: `ARPWEAVER FM`
- DX7-style patch import:
  - single-voice SysEx
  - 32-voice bank SysEx
- Full DX7-style internal patch model retained in runtime data
- Simplified macro UI layered over the full patch model
- Global root note and scale
- Chord module with independent on/off
- 8-step sequencer
- Chorus, delay, reverb, unison

## Important Accuracy Note

This project preserves a DX7-style patch data structure and uses DX-inspired runtime lookup/envelope/routing behavior. 

It is not claimed to be bit-identical to hardware DX7 or Dexed. The architecture is set up so the FM core can continue evolving toward closer parity.

## Package

The package artifacts generated by Wwise packaging are:

- `ArpweaverFm_v2025.1.6_Build9117_Authoring.Windows_x64.Release.tar.xz`
- `ArpweaverFm_v2025.1.6_Build9117_SDK.Common.tar.xz`

These are assembled into the Launcher bundle folder and zip located in the project root.

## Install In Wwise Launcher

1. Close Wwise Authoring.
2. Open Wwise Launcher.
3. Go to `Installed Plug-ins`.
4. Click `Add from directory`.
5. Select `ARPWEAVER_FM.zip`.
6. Install the plug-in for Wwise `2025.1.6.9117`.
7. Re-open Wwise.
8. Create a `Sound SFX`.
9. Click `Add Source`.
10. Select `ArpweaverFm`.

## Use

1. Click `Load SysEx` or `Import .syx`.
2. Select a DX7 `.syx` file.
3. Use `Prev Patch` and `Next Patch` to browse.
4. Enable `Use SysEx Patch` to drive the FM runtime from the imported patch.
5. Adjust global root note / scale, chord, sequencer, and FX parameters.
